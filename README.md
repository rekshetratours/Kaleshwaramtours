# KaleshwaramTours Website

Six-page static website for GitHub Pages.

## Files
- `index.html` – Home
- `temples.html` – Temples
- `sangamalu.html` – River confluences
- `ashta-theerthalu.html` – Ashta Theerthalu
- `pushkaralu.html` – Godavari Pushkaralu
- `packages.html` – Tour enquiries
- `style.css`, `robots.txt`, `sitemap.xml`

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `packages.html` with your business email.
2. Verify temple names, local routes, the eight traditional theertha names, timings, prices and access permissions with official/local sources.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Add the custom domain `kaleshwaramtours.com` in Pages after DNS is configured.
5. Submit `https://kaleshwaramtours.com/sitemap.xml` in Google Search Console after the domain is live.

The site uses a remote Unsplash image URL in the home-page hero. Replace it with a locally licensed image if desired.
